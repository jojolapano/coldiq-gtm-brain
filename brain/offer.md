# Offer — ColdIQ (the product we sell in this campaign)

Source: coldiq.com, read on 2026-10-21. Do not add claims that are not listed here.

## What it is
- One chat, one MCP server and one REST API over 40+ data providers and 700+ endpoints.
- Search companies and people, find and verify emails and phones, tech stacks,
  job postings and buying signals.
- Works where the GTM team works: Claude Code / Cursor / Codex (MCP), browser chat, Slack.
- Auto routing: picks the best provider per request; waterfall fallback when one comes up empty;
  every email verified.
- Provider keys and billing stay on ColdIQ's side: one account, one bill, one response format.
- Every provider stays callable directly: the router is the default, not a lock-in.

## Pricing (public)
- Free: 300 credits at sign-up, no credit card.
- Starter: from $99/month (7,000 credits). Scale: from $499/month (40,000 credits).
- Price of each call shown before it runs. No per-seat licence.

## Core angle for this campaign
A company hiring a GTM engineer is about to build a data + enrichment stack.
ColdIQ is that stack on day 1: one key instead of 10 provider contracts.
